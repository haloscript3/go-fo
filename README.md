# Go - Learning Journey 

This repository contains projects and examples created during my Go programming language learning process. It includes learning materials covering a wide range of topics from Go fundamentals to advanced concepts as part of a web-based bootcamp program.

## Learning Content

### Fundamentals
- **Introduction**: Introduction to Go programming language
- **Go Installation**: Setting up Go and development environment
- **Hello, World**: First Go program
- **Integers**: Numeric data types and operations
- **Iteration**: Loops and control structures
- **Arrays and Slices**: Data structures
- **Structs, Methods & Interfaces**: Object-oriented programming
- **Pointers & Errors**: Memory management and error handling
- **Maps**: Key-value pairs

### Advanced Topics
- **Dependency Injection**: Dependency injection patterns
- **Mocking**: Test doubles and mocking
- **Concurrency**: Concurrent programming with goroutines
- **Select**: Channel selection
- **Reflection**: Runtime reflection
- **Sync**: Synchronization primitives
- **Context**: Context management
- **Intro to Property Based Tests**: Property-based testing
- **Maths**: Mathematical operations
- **Reading Files**: File I/O operations

### Application Development
- **Build an Application**: Complete application development
- **HTTP Server**: Web server development
- **JSON, Routing and Embedding**: Data formats and routing
- **IO and Sorting**: Input/output operations and sorting
- **Command Line & Package Structure**: CLI applications
- **Time**: Time operations
- **WebSockets**: Real-time communication

### Testing & Quality
- **OS Exec**: Operating system commands
- **Error Types**: Error handling patterns
- **Context-aware Reader**: Context-aware readers
- **Revisiting HTTP Handlers**: Advanced HTTP handling
- **Meta**: Meta-programming concepts
- **Why Unit Tests and How to Make Them Work for You**: Testing best practices
- **Anti-patterns**: Common programming pitfalls
- **Intro to Generics**: Generic programming
- **Contributing**: Contributing to open source
- **Chapter Template**: Learning template

## Learning Objectives

Throughout this bootcamp, I will learn:

1. **Basic Go Syntax**: Variables, functions, control structures
2. **Data Structures**: Arrays, slices, maps, structs usage
3. **Concurrency**: Goroutines, channels, select statements
4. **Web Development**: HTTP servers, routing, JSON processing
5. **Testing**: Unit tests, mocking, property-based testing
6. **Best Practices**: Clean code, error handling, performance
